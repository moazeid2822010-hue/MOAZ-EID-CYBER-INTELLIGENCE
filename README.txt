MOAZ EID | CYBER INTELLIGENCE
=============================
هذه هي ملفات الموقع الأصلي بنفس التصميم، بعد ترتيبها لتكون جاهزة للرفع على GitHub Pages.

مهم جداً:
- افتح هذا المجلد بعد فك الضغط.
- ارفع الملفات والمجلدات الموجودة بداخله مباشرة إلى جذر المستودع (Root).
- لا ترفع مجلد MOAZ-EID-Cyber-Intelligence-FIXED نفسه.
- يجب أن يظهر index.html مباشرة في قائمة ملفات المستودع بجوار style.css و script.js ومجلد assets.

هيكل الملفات:
index.html
style.css
script.js
assets/

إعداد GitHub Pages:
Settings > Pages
Source: Deploy from a branch
Branch: main
Folder: /(root)
ثم Save وانتظر اكتمال النشر من Actions.

هذا التعديل لا يعيد تصميم الموقع؛ يحافظ على ملفات التصميم الأصلية.
